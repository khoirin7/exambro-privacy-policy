Kebijakan Privasi ExamBro

Computer Based Test Examination Browser

Terakhir diperbarui: 28 September 2026

1. Informasi yang Dikumpulkan

ExamBro adalah aplikasi Android yang dikembangkan untuk membantu pengguna mengakses dan mengikuti ujian berbasis komputer (Computer Based Test/CBT) melalui server ujian yang disediakan oleh sekolah atau penyelenggara ujian.

ExamBro tidak meminta pengguna membuat akun khusus di aplikasi dan tidak secara langsung mengumpulkan nama, alamat, nomor telepon, atau informasi identitas pribadi pengguna melalui aplikasi.

Aplikasi dapat mengakses atau memproses informasi berikut sesuai dengan fungsi yang digunakan:

  • URL server ujian, yang dimasukkan oleh pengguna atau diperoleh melalui pemindaian QR Code.
  • Kamera, yang digunakan untuk memindai QR Code server ujian.
  • Informasi koneksi internet, yang digunakan untuk mengetahui dan memastikan koneksi ke server ujian.
  • Status baterai perangkat, yang ditampilkan sebagai informasi selama penggunaan aplikasi.
  • Waktu pada perangkat, yang ditampilkan sebagai informasi selama ujian.

2. Penggunaan Informasi

Informasi tersebut digunakan untuk menyediakan fungsi utama ExamBro, termasuk:

  • Menghubungkan aplikasi ke server ujian.
  • Membuka halaman ujian melalui WebView.
  • Memindai QR Code untuk memasukkan alamat server ujian.
  • Menampilkan status koneksi internet, baterai, dan waktu.
  • Membantu memastikan aplikasi dapat berfungsi selama pelaksanaan ujian.

ExamBro tidak menjual informasi pribadi pengguna.

3. Server Ujian Pihak Ketiga

ExamBro dapat terhubung ke server ujian yang dikelola oleh sekolah, lembaga pendidikan, atau penyelenggara ujian.

Ketika pengguna mengakses server ujian melalui ExamBro, data yang dikirimkan atau diproses oleh server tersebut mengikuti kebijakan privasi dan ketentuan yang ditetapkan oleh pemilik atau pengelola server ujian.

ExamBro bukan pemilik atau pengelola data yang dikumpulkan oleh server ujian pihak ketiga tersebut.

4. Kamera dan Pemindaian QR Code

ExamBro menggunakan kamera perangkat hanya untuk fungsi pemindaian QR Code server ujian.

ExamBro tidak menggunakan kamera untuk mengambil atau menyimpan foto pengguna untuk tujuan lain.

5. Penyimpanan Data

ExamBro tidak menyediakan penyimpanan cloud atau akun pengguna sendiri untuk menyimpan data pribadi pengguna.

Data yang diproses oleh server ujian dapat disimpan oleh pengelola server tersebut sesuai dengan kebijakan dan sistem yang mereka gunakan.

6. Berbagi Informasi

ExamBro tidak menjual atau menyewakan informasi pribadi pengguna kepada pihak lain.

Ketika aplikasi terhubung ke server ujian, informasi yang diperlukan untuk komunikasi dengan server dapat diproses oleh server tersebut sesuai dengan fungsi layanan dan kebijakan pengelolanya.

7. Iklan

Versi ExamBro yang tercakup dalam kebijakan privasi ini tidak menampilkan iklan dan tidak menggunakan Google AdMob.

Jika fitur iklan ditambahkan pada versi mendatang, kebijakan privasi ini akan diperbarui sebelum fitur tersebut digunakan dalam aplikasi.

8. Keamanan

ExamBro menerapkan fitur keamanan aplikasi yang dirancang untuk membantu melindungi penggunaan aplikasi selama ujian.

Namun, tidak ada metode transmisi atau penyimpanan data melalui internet yang dapat dijamin sepenuhnya aman.

9. Privasi Anak

ExamBro dapat digunakan dalam lingkungan pendidikan. Aplikasi tidak secara langsung meminta informasi identitas pribadi dari pengguna.

Sekolah atau penyelenggara ujian bertanggung jawab atas data peserta yang mereka kumpulkan melalui sistem server ujian mereka.

10. Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui dari waktu ke waktu apabila terdapat perubahan pada fungsi, layanan, atau praktik privasi ExamBro.

Tanggal pembaruan terakhir akan dicantumkan di bagian atas halaman ini.

11. Hubungi Kami

Jika Anda memiliki pertanyaan mengenai Kebijakan Privasi atau penggunaan aplikasi ExamBro, Anda dapat menghubungi pengembang melalui kontak yang tercantum pada halaman aplikasi ExamBro di Google Play.
